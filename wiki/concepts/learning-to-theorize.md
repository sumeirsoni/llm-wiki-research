# Learning-to-Theorize

## Overview

Learning-to-Theorize (L2T) treats understanding as the induction of a reusable explanation from observations. The explanation is an executable program made from learned operations. A model succeeds when it can infer the program that maps one observation to another, apply that program to a new input, and compose the same operations in a new order.

[[learning-to-theorize-world-observation|Learning to Theorize the World from Observation]] presents L2T as a world-modeling objective that goes beyond predicting or reconstructing the next observation. Its Neural Theorizer (NEO) is a first implementation of the idea.

## What a theory contains

An L2T theory has a discrete vocabulary of primitive operations and a rule for composing them. A phenomenon is an observation pair $(x, y)$ generated by a hidden program $\tau$. The training data contains the pair but not $\tau$, the primitive meanings, or the execution trace.

The model learns a shared executor for the primitive operations. Sharing forces a primitive to work across examples instead of storing one code for every observed composite transformation. The test protocol then asks whether a program inferred from one pair transfers to another pair generated by the same hidden operation.

This transfer test matters because support reconstruction alone is weak evidence. A model can encode details of one target in a latent code and reconstruct it without learning a reusable transformation. Query transfer exposes that failure.

## How NEO implements L2T

NEO encodes the source and target observations, selects discrete primitive symbols with a goal-conditioned theory programmer, and applies a shared latent transition model. A VQ-VAE codebook supplies the discrete symbols. The symbols have learned operational semantics rather than predefined names.

NEO uses the Minimum Description Length principle to choose an explanation length for each pair. It also applies state grounding, which ties intermediate latent states to the encoder-decoder state space. In the reported ablation, removing grounding causes the primitive discovery and transfer metrics to collapse.

At test time, NEO composes primitives until its reconstruction threshold is met. NEO-S samples several candidate programs and uses the extra search budget to find a program that transfers over a longer or held-out composition. This search result is evidence that the model has a useful program space, but it does not show that every sampled program has an interpretable meaning.

## Evaluation axes

[[observation-to-theory-induction-benchmark|OTIB]] measures three kinds of generalization:

- **In-distribution:** The model explains programs from the observed composition range.
- **Compositional OOD:** The model combines primitives in a held-out order or combination.
- **Length OOD:** The model composes more operations than appeared in training.

Each evaluation item has a support pair and a query pair from the same hidden program. Self-explainability measures the support prediction. Transferability measures the query prediction. The latter is the central L2T measure because it tests whether the induced program is reusable.

## Relation to other approaches

- [[world-models]] usually evaluates a model by its prediction of future states. L2T adds an explicit program and a transfer test to the world-model objective.
- [[compositional-generalization]] studies whether learned rules transfer to unseen combinations and longer compositions. L2T tests the same capability through latent program induction from observations rather than a language-model recurrence task.
- [[iterative-refinement]] includes NEO as a sequential latent execution method. NEO's repeated steps choose and apply operations, rather than repeatedly refining one unrestricted hidden state.
- [[candidate-exploration]] shares the idea that extra test-time search can find a better candidate, but NEO searches over executable programs and evaluates transfer to a new input.

## Limits

The evidence comes from small, controlled domains with discrete operations and short programs. Reconstruction alone does not guarantee that learned primitives correspond to human concepts or causal mechanisms. The deterministic executor and reconstruction-based stopping rule may fail when observations are noisy or partially observed.
