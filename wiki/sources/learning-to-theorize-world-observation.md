# Learning to Theorize the World from Observation

## Summary

Baek et al. introduce Learning-to-Theorize (L2T), a learning paradigm that treats understanding as the induction of reusable explanations from raw observation pairs. The proposed Neural Theorizer (NEO) represents an explanation as an executable program made from learned primitive operations. It infers a program from one source and target pair, executes the same program on another source observation, and measures whether the result transfers. On the synthetic Observation-to-Theory Induction Benchmark (OTIB), NEO discovers primitive operations, transfers programs to new inputs, and composes operations that were not seen together during training. The evidence is a proof of concept. The experiments use small discrete program spaces, short horizons, and controlled GridWorld, arithmetic, and image-editing tasks.

## Key Contributions

- Defines L2T as the capacity to discover reusable primitives, compose them into executable explanations, and reuse those explanations on new phenomena.
- Proposes NEO, a probabilistic neural model with a learned discrete vocabulary of primitive operations and a shared latent-state executor.
- Introduces OTIB, which tests program transfer from a support observation pair to a query observation generated by the same hidden program.
- Reports compositional and length generalization without program labels, task groups, or symbolic supervision.

## Methodology

### Learning-to-Theorize

L2T models a phenomenon as an observation pair $(x, y)$ generated by an unobserved program $\tau$. A program is an ordered sequence of primitives drawn from a finite set $Z$:

$$
\tau = (z_{i_1}, z_{i_2}, \ldots, z_{i_K}), \qquad
f_{\tau} = f_{z_{i_K}} \circ \cdots \circ f_{z_{i_1}}.
$$

Training receives only $(x, y)$ pairs. The programs and the primitive execution functions remain latent. The training set contains a restricted subset of possible compositions. The test set holds out compositions and can contain programs longer than the training programs.

The paper evaluates whether an inferred program is reusable. NEO first infers $\hat{\tau}$ from a support pair $(x^{(1)}, y^{(1)})$. It then applies $\hat{\tau}$ to $x^{(2)}$. Transferability measures the error between the predicted and true query observations. This separates a model that reconstructs one target from a model that identifies the mechanism that generated the target.

### Neural Theorizer

NEO contains an encoder, a theory programmer, and a shared primitive executor. The encoder maps the source observation to a latent state. The theory programmer receives the current latent state and the encoded target observation, then chooses the next primitive. The executor applies that primitive to produce the next latent state. The resulting trace is decoded to reconstruct the target.

The general model uses a variational posterior over the program and execution trace. The practical implementation uses deterministic execution and a VQ-VAE codebook for the discrete primitive symbols. The codebook size is a hyperparameter because the true number of primitives is unknown. The symbols have no predefined meaning. The shared executor gives each symbol its operational meaning by learning how it changes a latent state.

NEO uses two controls on the latent program:

- **Minimum Description Length:** At every execution step, the model decodes an intermediate state and selects the shortest explanation whose reconstruction loss is low enough. The penalty is $\lambda_{\mathrm{MDL}}^k \ell(y, \hat{y}_k)$, so a larger weight favors shorter programs.
- **State grounding:** A decode-encode consistency loss keeps intermediate states near the encoder's valid latent-state manifold. The loss prevents the executor from using off-manifold shortcut states that only work at the final step.

At inference, the theory programmer selects primitives one at a time until the reconstruction error falls below a threshold. NEO-S samples multiple candidate programs and selects one by majority vote. The sampling budget is 64 on GridWorld and 1,024 on Arithmetic Factorization Reasoning in the reported tables.

### Observation-to-Theory Induction Benchmark

OTIB uses three evaluation regimes:

- **In-distribution:** The test program comes from the observed composition range.
- **Compositional OOD:** The test program uses a composition held out from training.
- **Length OOD:** The test program is longer than the training programs.

The split parameter $\alpha \in \{0.33, 0.66, 1.00\}$ controls the fraction of compositions included in training. Each test item contains a support pair and a query pair generated by the same latent program. Self-explainability measures reconstruction of the support target. Transferability measures reconstruction of the query target.

The benchmark has three domains:

- **GridWorld:** A 10 by 10 grid with hidden up, down, left, and right motion primitives. Training programs have lengths 1 to 3. Length OOD tests programs up to length 8.
- **Arithmetic Factorization Reasoning:** Integer pairs transformed by sequences of multiplication primitives from $\{\times2, \times3, \times5, \times7\}$. Training uses lengths 1 to 3. Length OOD uses lengths 4 to 6.
- **Image Editing:** CIFAR-10 images transformed by eight editing primitives, including rotation, brightness adjustment, and masking. Training uses lengths 1 to 2. OOD tests use lengths 3 to 4.

The baselines are a discrete monolithic conditional VQ-VAE, a continuous monolithic model, and a continuous monolithic model with program optimization. These baselines can reconstruct support targets but usually fail to transfer the inferred code to a new input.

## Key Results

- NEO maintains high transferability on held-out program compositions and longer programs, while the monolithic baselines often have near-zero transferability despite strong support reconstruction.
- On GridWorld with $\alpha=0.33$, NEO reaches 0.933 transferability on compositional OOD and 0.845 on length OOD. NEO-S raises these values to 0.976 and 0.907 with a sampling budget of 64.
- On Arithmetic Factorization Reasoning, NEO-S raises length-OOD transferability from 0.019 to 0.696 at $\alpha=0.66$ and from 0.023 to 0.707 at $\alpha=1.00$.
- NEO has the lowest reported L1 distance on both Image Editing OOD settings across all $\alpha$ values.
- Learned codebooks recover primitive-level operations even when some ground-truth primitives never appear alone in training. The reported primitiveness scores often approach 1.0.
- The MDL-selected length usually tracks the ground-truth number of operations. A high MDL weight of 1.2 encourages overly short, entangled explanations, while the tested weights 0.8 and 1.0 preserve primitive decomposition more reliably.
- Removing state grounding collapses training. Primitiveness falls to 0.002, and self-explainability and transferability fall to zero across the reported splits.
- An over-complete codebook with 36 entries still reaches primitiveness 1.0 and improves the base GridWorld transfer scores in Table 3. The model does not need a codebook sized exactly to the ground-truth primitive set in this experiment.

## Limitations & Open Questions

The paper is an initial proof of concept. It assumes a small discrete primitive set and short programs, so it does not establish scalability to long-horizon, continuous, or highly structured dynamics. NEO learns primitive semantics from reconstruction. The learned symbols therefore need not match human concepts or causal factors.

The practical model uses deterministic execution and a reconstruction threshold for stopping. Both choices may be brittle under noise, ambiguity, or partial observability. The experiments use controlled synthetic benchmarks rather than real sensory streams. They do not test stochastic transitions or open-ended theory spaces.

> [!open-question]
> Can L2T recover stable, causally useful programs from natural visual trajectories when the primitive set is continuous, noisy, and not known in advance?

## Future Work

- Extend L2T to real environments with richer perceptual inputs and longer-horizon dynamics.
- Replace the small discrete primitive vocabulary with continuous or open-ended theory spaces.
- Add stochastic execution and inference methods that handle noise, ambiguity, and partial observability.
- Test whether learned primitives support reliable interventions and counterfactual execution outside the controlled benchmarks.
