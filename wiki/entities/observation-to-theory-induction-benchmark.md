# Observation-to-Theory Induction Benchmark

## Identity

OTIB is the benchmark introduced by [[learning-to-theorize-world-observation|Learning to Theorize the World from Observation]]. It tests whether a model can infer a reusable program from raw observation pairs without program labels, symbolic supervision, or task grouping.

## Protocol

Each item contains a support pair and a query pair generated by the same hidden program. The model infers a program from the support pair, executes that program on both source observations, and produces two predictions.

- **Self-explainability** measures how well the inferred program reconstructs the support target.
- **Transferability** measures how well the same program reconstructs the query target.

OTIB uses $\alpha$ values of 0.33, 0.66, and 1.00 to control the fraction of program compositions included in training. It evaluates in-distribution, compositional OOD, and length OOD generalization.

## Domains

- **GridWorld:** A 10 by 10 grid with hidden motion operations. Training programs have lengths 1 to 3. Length OOD reaches length 8.
- **Arithmetic Factorization Reasoning:** Integer transformations built from multiplication by 2, 3, 5, or 7. Training uses lengths 1 to 3. Length OOD uses lengths 4 to 6.
- **Image Editing:** CIFAR-10 transformations built from eight editing operations. Training uses lengths 1 to 2. OOD tests use lengths 3 to 4.

## Interpretation

OTIB makes support reconstruction and program reuse separate measurements. A monolithic code can fit a support pair while failing to transfer. The benchmark therefore treats query transferability as the main evidence that a model learned a mechanism rather than an instance-specific code.

The benchmark remains controlled. Its primitive sets are discrete, its program lengths are short, and its observations come from synthetic or constrained transformations. Strong OTIB performance does not establish generalization to natural video, stochastic environments, or open-ended theory spaces.
